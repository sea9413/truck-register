# 装货登记小工具

一个手机上的装货登记工具，支持粘贴司机发来的信息自动识别，数据保存在云端，所有同事打开同一个网址就能一起用。

## 在线地址

https://sea9413.github.io/truck-register/

## 功能

- 📋 粘贴司机信息自动识别（日期、车牌、姓名、身份证、手机号、地址、货物、运费）
- 📱 手机浏览器直接打开，无需安装 App
- ☁️ 数据云端同步，所有同事共享
- 📤 一键复制通知文字，发微信群

## 使用步骤

1. 打开网址
2. 点「+ 新增登记」
3. 把司机发来的信息粘贴到识别框，点「识别」
4. 核对自动填入的内容，补填没识别的
5. 点「提交」
6. 点「复制通知文字」，去微信群粘贴发送

## 技术

- 前端：HTML + CSS + JavaScript
- 数据库：Supabase
- 部署：GitHub Pages
